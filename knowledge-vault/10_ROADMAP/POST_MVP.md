# Post-MVP Features

- **EditDNA:** Extracting style from reference videos.
- **Critic Agent:** An AI that reviews the Editor Agent's work before the human sees it.
- **Style Profiles:** Switching between "Hype Editor", "Chill Editor", "Narrative Editor".
- **Fine-tuning Feedback:** Using human adjustments in the UI to update the Style Profile weights.
