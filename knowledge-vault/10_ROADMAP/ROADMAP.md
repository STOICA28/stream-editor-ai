# Roadmap

- **M0 - Foundation:** Repository, Vault, Basic API/DB structure.
- **M1 - Ingestion:** Media upload, probing, analysis proxy generation.
- **M2 - Analysis Pipeline:** WhisperX, scene detection, visual events.
- **M3 - Editorial Core:** Scoring, basic story graph, EditPlan generation.
- **M4 - Rendering:** FFmpeg execution of basic cuts.
- **M5 - Review UI:** Web interface for playing back the rough cut.
- **M6 - Effects:** Remotion integration for zooms, text.
- **M7 - Critic Agent:** Self-correction loop.
- **M8 - EditDNA Pipeline:** Reference video analysis.
- **M9 - Advanced Story Graph:** Complex narrative tracking.
- **M10 - 1.0 Launch:** Public beta.
