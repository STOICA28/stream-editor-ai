# Architecture Decision Records (ADRs)

How to write ADRs:
1. **Title:** Short, descriptive.
2. **Context:** What is the problem?
3. **Decision:** What did we choose to do?
4. **Consequences:** Good and bad outcomes.
5. **Status:** Proposed, Accepted, Deprecated.
