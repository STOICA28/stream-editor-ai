# MVP Acceptance Criteria

1. Create project
2. Import local video
3. Inspect metadata
4. Generate analysis proxy
5. Transcribe audio
6. Detect scenes
7. Generate TimelineEvents
8. Generate candidate moments
9. Obtain candidate scores
10. Create basic EditPlan
11. Render rough-cut preview
12. Review proposed clips in web UI
13. KEEP/CUT segments
14. Change segment boundaries
15. Rerender
16. Export MP4
