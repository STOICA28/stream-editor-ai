# User Workflows

1. **Process a new VOD:** User creates a project, uploads/links a VOD, and triggers the processing pipeline.
2. **Review and approve clips:** User views the proposed EditPlan in the web UI, adjusting boundaries and KEEP/CUT decisions.
3. **Render final video:** User confirms the EditPlan and triggers the final high-quality render.
4. **Analyze a reference video (EditDNA):** User provides a raw VOD and its human-edited counterpart to train the system on their specific style.
5. **Review research findings:** User reviews findings generated by the Research Agent and promotes valid ones to canonical rules.
