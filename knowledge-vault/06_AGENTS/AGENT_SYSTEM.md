# Agent System Overview

The StreamEditor AI system uses a multi-agent architecture. Agents are specialized, have distinct tools, and operate with different models depending on the required capability.

- **Architect Agent:** System integrity, ADRs, conflicts.
- **Research Agent:** EditDNA analysis, hypothesis generation.
- **Media Analysis Agent:** Data extraction, event timeline generation.
- **Editor Agent:** AI judgment, narrative assembly, EditPlan creation.
- **Critic Agent:** EditPlan review, suggestion generation.
- **Vault Curator Agent:** Documentation maintenance, inbox triage.
