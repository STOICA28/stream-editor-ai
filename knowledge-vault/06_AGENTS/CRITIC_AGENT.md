# Critic Agent

**Role:** Quality assurance for the AI.
**Responsibilities:**
- Inspect generated `EditPlans`.
- Compare against pacing, context, and storytelling rules.
- Identify dead air or broken callbacks.
- Produce a new validated `EditPlan` version incorporating fixes.
