# Context Policy

Context windows are essential so clips don't feel jarring.

- **Minimum pre-context:** 2-5 seconds before an event (e.g., before someone starts speaking or an action happens).
- **Minimum post-context:** 3+ seconds after a payoff lands to let it breathe.
- **Sentence Integrity:** Never cut a sentence in the middle unless for intentional comedic effect (abrupt cut).
