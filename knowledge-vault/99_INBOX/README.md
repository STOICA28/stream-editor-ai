# Inbox

This directory is for unreviewed findings and ideas.

- The **Research Agent** deposits new hypotheses here.
- Human users can dump quick notes here.
- The **Vault Curator** periodically reviews this folder, formats findings, checks for conflicts, and promotes accepted rules to the `03_EDITORIAL_BIBLE`.

Items here should NOT be considered canonical by the Editor Agent.
